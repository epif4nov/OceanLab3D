# OceanLab 3D

Интерактивный учебный атлас океанического рельефа на React, Three.js и React Three Fiber.

## Запуск

```bash
npm install
npm run dev
```

Управление сценой: левая кнопка мыши — вращение, колесо — масштаб, правая кнопка — панорама. Рельеф процедурный и схематичный; глубины и горизонтальные расстояния не представлены в едином масштабе.
